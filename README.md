# Universal BI Frontend

Фронтенд-прототип для проекта **«Разработка универсальной BI-системы для ERP-систем»**.

## Что реализовано

- главная панель с KPI и дашбордами;
- раздел отчетов;
- раздел источников данных и мониторинга ETL / ELT;
- раздел KPI;
- раздел администрирования ролей;
- раздел документации;
- переключение ролей пользователя на клиенте;
- сообщения для функций, где требуется серверная логика.

## Что не реализовано намеренно

Согласно условию, операции, требующие серверной части, не выполняются, а показывают сообщение:

- реальная авторизация;
- запуск ETL;
- экспорт файлов;
- сохранение ролей;
- синхронизация пользователей;
- публикация документации;
- интеграция с ERP-системами.

## Быстрый старт

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

Проверка типов:

```bash
npm run lint
```

## CI/CD

В репозитории есть workflow GitHub Actions:

- установка зависимостей;
- проверка TypeScript;
- сборка проекта;
- публикация артефакта сборки.

Для деплоя на GitHub Pages можно добавить отдельный workflow или шаг deploy в зависимости от выбранной стратегии публикации.
